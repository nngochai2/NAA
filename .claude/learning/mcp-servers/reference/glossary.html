MCP Servers · Reference

Glossary

Canonical vocabulary for this workspace. Established in Lesson 1. Use these words, not the aliases listed under each.

Core roles

Host:
The LLM application that initiates connections and decides when to invoke a server's capabilities — e.g. Claude Desktop, Claude Code.
Avoid: client app, the AI

Client:
The connector living inside the host, one per connected server, that speaks JSON-RPC on the host's behalf. You do not write this.
Avoid: the AI, the caller

Server:
The process you write that exposes tools, resources, and/or prompts to a host over a transport. Everything in mcp/ in this repo is a server.
Avoid: the integration, the backend

Primitives

Tool:
A model-invoked function: a name, a JSON Schema for its arguments, and a result. The only primitive currently used anywhere in mcp/.
Avoid: function, action, endpoint

Resource:
An application- or user-controlled, read-only, side-effect-free piece of context addressed by URI — the GET-like primitive. Not yet used in this repo.
Avoid: data source, context object

Prompt:
A reusable, user-invoked message template exposed by a server (e.g. a slash command). Not yet used in this repo.
Avoid: template, macro

Transport

Transport:
The mechanism JSON-RPC messages travel over between client and server.
Avoid: protocol (protocol is the message format; transport is the pipe)

stdio transport:
Server runs as a local child process; messages travel over stdin/stdout. Not used by any server in this repo (all use SSE).
Avoid: local mode

SSE transport:
Server runs as an HTTP service; it pushes messages over a Server-Sent Events stream while the client posts back to a separate endpoint. Used by every server in mcp/ today.
Avoid: streaming mode, HTTP mode (too vague — streamable HTTP is a distinct, newer transport)

SDK terms — disambiguation

Low-level API (mcp.server.Server):
The SDK layer requiring hand-written Tool objects, explicit list_tools/call_tool handlers, and manual transport wiring. Used by mcp/jira.
Avoid: raw API, manual API

High-level API (mcp.server.fastmcp.FastMCP):
The SDK layer that generates JSON Schema from type hints/docstrings via decorators and wires the transport for you. Used by mcp/src (knowledge-graph). Bundled inside the official mcp package — not the same thing as the standalone PrefectHQ fastmcp PyPI package.
Avoid: "FastMCP" unqualified when the distinction from the standalone package matters
